Les règles du voyage

  1. Configurez les joueurs, les cartes de l’autoroute et les checkpoints.
  2. Révélez la carte de l’étape, puis le joueur annonce Plus, Moins ou Égal.
  3. Le croupier tire une carte : comparez uniquement sa valeur. 2 < 3 … < Valet < Dame < Roi < As.
  4. Bonne réponse : avancez d’une carte. Un checkpoint franchi reste acquis.
  5. Erreur : comptez les cartes depuis le dernier checkpoint acquis (ou le départ), en incluant la carte de l’échec. Première carte après le checkpoint : +1 point ; troisième carte : +3 points. Retour après le dernier checkpoint acquis, ou à la première carte.
  6. Après chaque tirage, réussi ou raté, la carte tirée remplace celle du bus à cette étape. Cette nouvelle valeur sert aux prochains passages.
  7. Chaque joueur joue jusqu’au bout avec une nouvelle autoroute et un paquet de 52 cartes mélangé. Le plus petit score gagne ; les ex æquo partagent la place.

Seules les anciennes cartes remplacées sont défaussées. Quand la pioche est vide, seule la défausse est remélangée. Les cartes présentes dans le bus ne retournent pas dans la pioche.

La partie est sauvegardée sur cet appareil lorsque le navigateur le permet.
