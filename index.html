Les règles du voyage

  1. Les joueurs forment une seule équipe. Ils partagent la même autoroute, les checkpoints et le compteur de gorgées. Une personne peut aussi jouer seule.
  2. Le joueur actif clique sur la carte indiquée sur le parcours. Elle se retourne si elle est cachée ; si elle est déjà visible, le choix s’ouvre directement.
  3. Choisissez Plus ↑, Moins ↓ ou Égal =. Le croupier tire automatiquement. Seule la valeur compte : 2 < 3 … < Valet < Dame < Roi < As.
  4. Bonne réponse : l’équipe avance. Un checkpoint franchi reste acquis pour toute l’équipe.
  5. Erreur : comptez les cartes depuis le dernier checkpoint acquis (ou le départ), carte de l’échec comprise. Première carte : +1 gorgée ; troisième : +3 gorgées. Retour après le checkpoint, ou à la première carte.
  6. Après chaque tirage, réussi ou raté, la carte tirée remplace celle du bus à cette étape. Sa nouvelle valeur sert aux prochains passages. L’ancienne carte est défaussée.
  7. Le tour passe au joueur suivant après chaque prédiction, même en cas d’erreur. L’équipe gagne en atteignant l’arrivée avec le moins de gorgées possible.

Quand la pioche est vide, seule la défausse est remélangée. Les cartes du bus restent en place. La partie est sauvegardée localement lorsque le navigateur le permet.
