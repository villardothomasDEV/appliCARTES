Les règles du voyage

  1. Configurez les joueurs, les cartes de l’autoroute et les checkpoints.
  2. Révélez la carte de l’étape, puis le joueur annonce Plus, Moins ou Égal.
  3. Le croupier tire une carte : comparez uniquement sa valeur. 2 < 3 … < Valet < Dame < Roi < As.
  4. Bonne réponse : avancez d’une carte. Un checkpoint franchi reste acquis.
  5. Erreur : +1 point, la carte tirée remplace la carte de l’étape. Retour après le dernier checkpoint acquis, ou à la première carte.
  6. Chaque joueur joue jusqu’au bout avec une nouvelle autoroute et un paquet de 52 cartes mélangé. Le plus petit score gagne ; les ex æquo partagent la place.

Les cartes tirées sur un succès et les cartes remplacées sont défaussées. Quand la pioche est vide, seule la défausse est remélangée. Les cartes de l’autoroute restent en place.

La partie est sauvegardée sur cet appareil lorsque le navigateur le permet.
